### Done

- **Audit (§2).** `crates/stats-core/examples/statrs_audit.rs` measures raw statrs
  0.19 against R. Findings: no log-tail API (ln(cdf) underflows to -inf); binomial
  CDF error 5e-4 at n = 1e6 (continued fraction stops before convergence);
  negative binomial 6e-7; F SF 0 instead of 6e-11; upper-tail quantiles off by
  1–28% near p = 1; Poisson λ = 0 and point masses rejected; gamma/chi-square
  quantiles use slow bisection. Existing workarounds: OLS `t_critical_95`
  bisection, probit Mills-ratio continued fraction.
- **Dependency.** Added `cdflib = "=0.4.3"` (MIT, Vigna; TOMS 708 incomplete
  beta, TOMS 654 incomplete gamma, Cody normal; computes both tails
  independently). GPL nmath ports (`rmathlib`, `r_mathlib`) were rejected for
  licensing. statrs stays for the estimators. Dev-only: `serde_json`
  `float_roundtrip` (the default parser misread fixture inputs by one ulp).
- **Core module** `crates/stats-core/src/distributions/`:
  - `continuous.rs`: Normal, StudentT, ChiSquare, FisherF, Beta, Gamma
    (shape/scale), Exponential (rate), LogNormal, Logistic.
  - `discrete.rs`: Binomial, Poisson, NegativeBinomial (`new(size, prob)` and
    `with_mean(size, mu)`). This covers all Tier 1 and Tier 2 distributions.
  - `special.rs`: log-scale tails used only below 1e-280 (normal Mills-ratio
    continued fraction, incomplete-gamma series/fraction, incomplete-beta
    fraction); Loader saddle-point densities (`stirling_error` table generated
    with mpmath, `deviance_term`, Poisson/binomial raw densities).
  - `quantile.rs`: log-scale safeguarded Newton for continuous quantiles; for
    discrete, the smallest k with F(k) ≥ p, with a 64ε relative fuzz on the
    smaller tail.
  - `mod.rs`: the shared policy:
    - finite parameters; ±∞ evaluation points allowed, NaN rejected (1003);
    - p must be in [0, 1] (1001);
    - out-of-support points give 0 or -∞;
    - a NaN result becomes error 1006.
- **Descriptive** `crates/stats-core/src/descriptive.rs`:
  - mean, variance and sd (sample/population), covariance and correlation (NaN
    when an input is constant);
  - quantile/quantiles (R type 7, exact R index arithmetic) and median;
  - weighted mean and weighted variance (frequency, reliability or population).
  - Sums are Neumaier-compensated, with a corrected two-pass algorithm.
- **PHP bindings** `crates/php-extension/src/distributions.rs` and `descriptive.rs`:
  - 13 parameterizations × 7 operations × scalar + `_array` = 182 functions, plus 10
    descriptive functions.
  - A `Real` argument type accepts PHP ints for float parameters (ext-php-rs f64
    rejects ints).
  - Batch functions stream the input and write a presized output array; they
    return a list (keys dropped) in input order, and `[]` for empty input.
  - Descriptive functions use `missing: 'raise'` by default, with `'drop'`
    pairwise.
  - Stubs and `tests/fixtures/php-api.json` are regenerated (v0.1 entries
    unchanged); `scripts/php-stubs.php` writes docblocks for the new families.
- **References:**
  - `tests/generate-distribution-fixtures.R` writes `distributions-r.json` (553
    cases including extreme tails) and `descriptive-r.json`.
  - `docs/verifications/compare_distributions.py` (needs the notebooks venv plus
    mpmath) writes `distributions-scipy.json`, `distributions-mpmath.json` (60
    digits, correctly rounded) and `docs/verifications/distributions-results.json`
    (errors of PHP, R and SciPy against mpmath).
  - The PHP runner is `docs/verifications/distributions.php`.

### Accuracy findings to document

- Typical relative error against mpmath is ≤ 1e-13. The worst case is about
  8e-13, in gamma/chi-square/Poisson tails with shape ≥ 1e4: cdflib's Temme
  regime. R is slightly better there.
- R itself is wrong in places (mpmath-confirmed):
  - `qt` at df < 1 in the far tail (1.7e-6);
  - `qf` returns 0 for tiny p with df1 ≤ 2;
  - `qt(0.5, 0.5)` returns 2.6e-16 instead of 0;
  - `df(Inf)` returns NaN;
  - `dnbinom_mu` for size ≫ x (an approximation);
  - its discrete-quantile fuzz at p = 1 − 2⁻⁵².
- Intentional difference: discrete quantile at p = 1 for a point mass follows
  the definition (e.g. binomial prob = 0 → 0), while R and SciPy return the
  support's upper bound.
- Subnormal results carry fewer significant bits. Scaled densities now
  exponentiate the log density so they no longer underflow before the Jacobian
  (fixed after the first review; covered by a Rust test).
